Opening the start form of a campaign moves the form twice within its first second:

1. The section with the target is drawn empty, then filled: everything below moves down (61 px at
   960x1080 in R-02).
2. The suggestions of "environments" and "kpis" are drawn once their reads have answered: each of
   the two fields grows by 33 px and moves the fields below it.

A probe that reads the browser's `layout-shift` entries with their sources, one run per viewport,
gave per page load a sum of 0.032 to 0.050 with the theme of R-01 and 0.042 to 0.057 with the theme
of R-02: the labels and suggestions are larger since UXF-017 closed, so late content is taller.

The page checks count only the shifts after the page reports ready (`main` without a loading mark).
The second movement lands within about 25 ms of that mark, before it in one run and after it in the
next. So the number measured on unchanged input is not one number:

| input | `layout_shift.after_ready@1` of the start form, per run |
|---|---|
| R-01 as recorded | 0.0151 |
| the document and theme of R-01, measured again for R-02 | 0.026 |
| the theme of R-01, 4 more runs | 0.0129, 0.0208, 0.0208, 0.0129 |
| R-02 | 0.0176 |
| the theme of R-02, 5 more runs | 0.0284, 0.0176, 0.0284, 0.003, 0.0284 |

`page_checks.layout_shift.max` of a round is this page's value in all three rounds. A ratchet on it
with the skill's tolerance of 0.01 would fail and pass on the same input.
`docs/browser-adapter.md` reports the same of another site: sampled layout shift values vary from
run to run.

Cause, read in the generated runtime (`src/runtime/fields.tsx`, `TagsInput`): the element that holds
the suggestions does not exist until there is one to show, so no rule of the theme can keep its
place free. That is the stock generator's: a known loss candidate. What the studio can do in its own
document: put the target beside the form, not above it, so the first movement does not reach the
form.

Heuristic 4 (stable layout): partial.

Triage: frequency 1 of 11 scenarios (start-campaign), confidence 2 (the page checks and the probe
agree), cost L. Priority 0.05.

Fix in one line: keep the place of late content free before it arrives, and measure the shift of
this page over several runs.
