# The 16 heuristics for L7

From a colleague's loop (shared 2026-10-19), worded for any UI. "The user" was the screen-only user's
human counterpart: the person working the UI.

1. One next thing: the screen names one next action.
2. State in words: the task's state is said in words, not only colour or icons.
3. Nothing required hidden.
4. Stable layout: nothing jumps while the user works.
5. Provenance of every value: the user can tell where a value came from.
6. Errors cheap: any fix takes at most 2 actions.
7. Words the user can say: labels the user can read out unchanged.
8. The counterpart's time respected: the UI never makes someone else wait.
9. Keyboard and pointer parity.
10. Recognition over recall.
11. Calm by default: no motion or alert without cause.
12. One state vocabulary across the UI.
13. A wrong cue recovered in one action.
14. Unmistakable end state.
15. Readable in every theme; key data at 14 px or more.
16. Focus follows the work: the active region is where the user's attention is.

Docs site: 8 reads as "the reader's time respected", 13 and 16 apply to navigation and search.
